## Pro、Eyeball、Tier 1 的区别：去程和回程走哪张网

三条线最直接的差别在回程。Pro 是旗舰，回程三网都走 CN2 GIA；Eyeball 走 CMIN2，价格低一档；Tier 1 用国际线路，不对中国大陆做专项优化。

具体到线路：

- **洛杉矶 Pro**：电信、联通去程 CN2 GIA，移动去程 CMI，三网回程 CN2 GIA。
- **洛杉矶 Eyeball**：电信、联通去程 CN2，移动去程 CMIN2，三网回程 CMIN2。
- **香港 Pro**：电信双向 CN2 GIA，联通走 AS9929 精品网或直连，移动 CMI。
- **东京 Pro**：电信 CN2 GIA，联通 AS9929，移动 CMI，在售两条线分别对应 Pro 与 T1。
- **T1**：国际标准线路，适合面向全球用户的项目，国内访问不做保证。

这里有一条很多人买完才发现：Pro 以外的产品可能因为网络攻击或成本原因切换路由。官方没有承诺 EB 和 T1 永久保持某条线路，如果业务对高端优化线路是刚需，直接买 Pro，不要指望用 EB 的价格拿到 Pro 的稳定性。

流量用超之后不停机，这一点几条线都一样，处理方式是限速继续跑。多个来源给出的限速档位是洛杉矶 T1 降到 100Mbps、香港和东京 T1 降到 50Mbps，日常 SSH 和轻量建站能撑到下个计费周期；Pro 系列超量后的限速更低，有资料写作 4Mbps。具体数值以官网条款页为准，各套餐之间不完全一致。

## 机房怎么选：香港、洛杉矶、东京，以及已经停售的圣何塞

第一段先给结论。香港延迟最低、单价最贵、最容易缺货；洛杉矶性价比最好，同时兼顾国内和海外访问；东京面向亚太，热门档位经常补不上货。

**香港**的最大卖点是物理距离。第三方测评给出的国内平均延迟在 39ms 左右，另一份测评写"50ms 以内"，两个数字口径不同，但都说明它是三地里唯一能做到 50ms 量级的机房。代价是同样的钱买到的流量只有洛杉矶的几分之一，MongKok 200GB/月对绝大多数站点都偏紧。

**洛杉矶**是多数人的落点。CN2 GIA 三网回程，第三方自述的电信联通延迟在 160ms 左右，移动稍高但也在 200ms 以内。买之前可以先用测试 IP 自己 ping 一遍：洛杉矶 Pro 是 `154.17.30.96`，洛杉矶 Eyeball 是 `154.17.229.24`。

**东京**适合面向日本、韩国和东南亚的项目，线路是 CN2 GIA 加 9929 加 CMI 的组合，机房经常缺货，能不能买到看运气。

**圣何塞（SJC）已经没有了**。这个机房 2023 年失去 AS4837 核心线路之后就开始走下坡，2025 年正式停售。前排一些老文章还在推荐"便宜的 SJC 套餐"，那是过期信息，新用户直接看洛杉矶系列，别在二手市场和论坛里找 SJC 的库存。

## 买之前必须接受的几个门槛

这部分是退款和售后争议的高发区，比价格更值得先看。

**只提供 Linux**。没有 Windows VPS，需要 Windows 环境的直接排除。

**默认用 SSH 密钥登录**。首次购买后要在后台下载密钥文件，再用终端或 Xshell 之类工具连接。新手会卡在这一步，配置一次之后确实比密码登录省心。关于能不能在面板里设置 root 密码，几份资料说法不一致，下单页怎么写就怎么办。

**IP 被墙可以免费换，每 15 天一次**。其它情况换 IP 收费 5 美元一次。做站的人对这个频率要有预期：15 天内二次被封，就得等到窗口刷新。

**退款政策相对宽松**。3 天内无理由全额退款，30 天内按剩余价值退款，可以退到账户余额，也可以退回原支付方式（原路退回会扣支付手续费）。买了发现线路不合适，3 天内退掉是成本最低的止损方式。

**支付和语言**。支持支付宝、微信、PayPal、信用卡，后台界面英文，工单可以中文沟通。如果你完全不想看英文，这不是个好选择。

**备份要自己做**。任何 VPS 都不保证数据安全，定期把数据同步到本地或另一个存储是基本操作。

**升级可以，降级要重买**。配置选低了可以直接升，选高了想降只能重新下单，所以第一次买宁可低一档。

## 哪些人不需要买 DMIT

- 只想花几美元练手、跑个临时脚本，DMIT 最便宜的档位也比这类需求贵，用别家更划算。
- 需要 Windows 远程桌面。
- 需要一键部署面板、图形化管理，不想碰 SSH 密钥。
- 对流量需求大但对线路不敏感，香港 Pro 200GB/月 的额度会让你每月算着用。

同赛道里的搬瓦工可以作为参照：它和 DMIT 都做 CN2 GIA，DMIT 是搬瓦工的上游之一。搬瓦工的 CN2 GIA 套餐流量通常给得更多，价格也相对亲民；DMIT 走自己的网络，线路更纯粹，不超售，代价是贵和缺货。两边都符合事实的差别大致如此，选哪个取决于你更在意单价还是线路确定性。
